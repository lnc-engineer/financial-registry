Parent Span Event Tracking

This session extended execution events with ParentSpanID support.

Execution contexts already supported parent-child span relationships,
but execution events only exposed TraceID and SpanID information.

By adding ParentSpanID to execution events, every event now records
its position within the execution hierarchy.

Example:

ROOT SPAN
└── CHILD SPAN

Each event generated by the child span now includes:

- TraceID
- SpanID
- ParentSpanID

This allows trace relationships to be reconstructed from stored
execution events and prepares the system for future trace tree
visualization and distributed tracing capabilities.
